# Анализатор метрик Холстеда для программ на Ruby

Программа-парсер с графическим интерфейсом. Читает исходный код на языке
**Ruby**, выделяет операторы и операнды и рассчитывает метрики Холстеда:
**6 базовых** и **3 расширенные** — по примеру из методических указаний.

## Состав

| Файл | Назначение |
|------|------------|
| `halstead_ruby.py` | Сама программа (парсер + графический интерфейс на Tkinter) |
| `sample_program.rb` | Пример кода на Ruby для анализа (~99 строк: все основные операторы языка и 6 пользовательских подпрограмм) |
| `Отчёт_метрики_Холстеда_Ruby.docx` | Отчёт с таблицей ручного расчёта метрик |
| `interface_preview.png` | Скриншот интерфейса |
| `README.md` | Этот файл — инструкция по запуску |

## Что считает программа

**6 базовых метрик** (выводятся в двух таблицах, как в Таблице 2 методички):

- **η₁** — словарь операторов (число уникальных операторов);
- **η₂** — словарь операндов (число уникальных операндов);
- **N₁** — общее число операторов;
- **N₂** — общее число операндов;
- **f₁ⱼ** — частота каждого оператора (столбец в таблице операторов);
- **f₂ᵢ** — частота каждого операнда (столбец в таблице операндов).

**3 расширенные (производные) метрики** (выводятся отдельным блоком внизу):

- **η = η₁ + η₂** — словарь программы;
- **N = N₁ + N₂** — длина программы;
- **V = N · log₂ η** — объём программы (в битах).

## Запуск на macOS

1. Проверьте, что установлен Python 3 (он есть в системе по умолчанию):

   ```bash
   python3 --version
   ```

2. Для графического интерфейса нужен модуль **Tkinter**. Проверьте:

   ```bash
   python3 -m tkinter
   ```

   Если открылось маленькое тестовое окошко — всё готово.
   Если появилась ошибка `ModuleNotFoundError: No module named 'tkinter'`,
   установите Tk одной командой:

   ```bash
   brew install python-tk
   ```

   (если нет Homebrew — можно поставить Python с сайта python.org,
   там Tkinter уже входит в комплект).

3. Запустите программу из папки с файлами:

   ```bash
   python3 halstead_ruby.py
   ```

## Как пользоваться

1. В окне уже вставлен пример кода. Можно также нажать **«Открыть .rb…»**
   и выбрать файл `sample_program.rb` (или любой свой `.rb`-файл), либо
   вставить код вручную, либо нажать **«Вставить пример»**.
2. Нажмите **«Анализировать ▶»**.
3. Слева появится таблица операторов (j, Оператор, f₁ⱼ) с итогом η₁ и N₁,
   справа — таблица операндов (i, Операнд, f₂ᵢ) с итогом η₂ и N₂.
   Внизу — три расширенные метрики η, N, V.

## Правила выделения операторов и операндов (для Ruby)

- **Не учитываются**: пробелы, переводы строк, комментарии (`# …` и блок
  `=begin … =end`).
- **Операнды**: имена переменных (`x`, `@a`, `@@b`, `$g`), константы-значения,
  литералы (числа, строки, символы `:foo`, регулярные выражения,
  `true`/`false`/`nil`). Имя операнда — его текст, частота — число вхождений.
- **Операторы**:
  - символьные операции (`+ - * / % ** == != < > <= >= = += … && || ! & | ^
    << >> .. ... ? : => -> . &. :: , ;`);
  - парные скобки — **одна** операция на пару: `( )` — группировка,
    `имя( )` — вызов метода/функции, `[ ]` — индексация, `{ }` — блок/хэш;
  - имена методов/функций (вызовы) — операторы (как `Readln`, `Writeln`,
    `abs` в примере методички);
  - управляющие «составные» операторы — одно вхождение на пару
    «открывающее слово … `end`»: `def…end`, `class…end`, `begin…end`,
    `case…end`, `if…end`, `unless…end`, `while…end`, `until…end`,
    `for…end`, `do…end`. Промежуточные слова (`then`, `else`, `elsif`,
    `when`, `rescue`, `ensure`) входят в составной оператор;
  - постфиксные модификаторы `if/unless/while/until` (без `end`) помечаются
    как `…(mod)` и считаются отдельным оператором.
- Метки к операторам и операндам не относятся.
